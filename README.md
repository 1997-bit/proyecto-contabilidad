# Proyecto Semestral

## Descripción

Aplicación web desarrollada en PHP para la administración
de colaboradores, cálculo de planillas y generación
de reportes empresariales.

## Stack

| Componente        | Tecnología |
| ----------------- | ---------- |
| Backend           | PHP 8.4    |
| Servidor          | Apache     |
| Base de datos     | MariaDB    |
| Administración DB | phpMyAdmin |
| Entorno local     | XAMPP      |
